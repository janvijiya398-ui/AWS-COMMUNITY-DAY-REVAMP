# AWS Student Community Day Revamp

A student-focused redesign of the AWS Student Community Day website.

## Project Overview

This project redesigns the AWS Student Community Day experience around the student attendee journey.

The prototype helps students:

- Understand the event
- Explore sessions
- Filter sessions by difficulty and type
- View speakers
- Register for the event
- Save sessions
- Manage selected sessions through the My Event dashboard
- Add the event to their calendar

## Main Pages

- Home
- Schedule
- Speakers
- Registration
- My Event

## Problems Identified

The original website mainly presented event information, but the student journey was not clearly connected. Students needed an easier way to discover relevant sessions, register, and manage their selected sessions after registration.

## Design Decisions

I focused on:

- Clear navigation
- Session filters
- Easy registration
- Speaker discovery
- A personal My Event dashboard
- Mobile responsiveness
- Clear calls to action
